# Plagiarism Policy

Any two students' code are quite similar is a plagiarism. If two submissions are found to be similar, both submissions get '0' in the assignments.

You are responsible for ensuring that your code/logic is not leaked until the assignment evaluations are over for everybody.

The following reasons are not accepted as excuses:

1. The other person took a photo of my code while I was coding
2. The other person stole my code
3. We looked at the same resource for the logic on the internet
4. We just discussed the ideas, so our codes have high similarities
5. The other person pressurized to share the code
6. I do not know how the other person got my code
7. This is the most natural way; I guess the other person would have thought the same way
8. Any form of re-use of the code from the instructor or TAs (Teaching Assistants) unless specified that you can use it. (In this case, only the code shared with you should be similar. Any modifications to the code shared with you should not match with high similarity with other participants)
